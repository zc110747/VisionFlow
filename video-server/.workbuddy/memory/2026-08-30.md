## Video Server 项目初始化（中心视频服务器 + Web 管理平台）

按用户提供的 24 节规格从零搭建完整工程。技术栈：Go 1.22 + MediaMTX + SQLite(modernc 纯 Go) + Vue3/TS/Vite/Element Plus。

- 目录：`cmd/video-server`(单体入口) + `internal/{api,camera,stream,database,mediamtx,monitor,config,logger,server}` + `web/`(前端, `web/embed.go` 用 `//go:embed all:dist` 嵌入) + `config/` + `scripts/` + `mediamtx/` + `tools/ffmpeg/`。
- MediaMTX 作为子进程由 Go 拉起；`mediamtx.Manager.GenerateConfig` 从 `config.yaml` 生成 `config/mediamtx.yml`（api :9997 / rtsp :8554 / webrtc :8889 / hls :8888，paths.all_others.source=publisher 允许任意路径推流）。
- Camera 自动发现：monitor 轮询 `GET 127.0.0.1:9997/v2/paths/list`，按 stream_path 自动建表；有 publisher 且 state=ready→online，超时(10s)无数据→offline。
- WebRTC：浏览器 SDP offer → `POST /api/cameras/{id}/webrtc` → Go 转发 `http://127.0.0.1:8889/<path>` 取 answer（规避 CORS）；前端 `webrtc/player.ts` 断线退避自动重连。
- 所有端口走 `config.yaml`，不硬编码。

### 环境安装
- 下载 `go1.27.0.windows-amd64.zip`（golang.google.cn）→ 解压到 `.toolchain/go`（已加 .gitignore，新增 `scripts/setup-go.bat` / `setup-go.sh` 可复现）。

- 编译坑修复：`web/embed.go` 包名 `webstatic` 但目录是 `web/`，故 server.go 应 `import "video-server/web"`（非 internal/webstatic）；server.go 需 `database/sql` 且去掉未用的 `internal/database`。修复后 `go build -trimpath -o video-server.exe ./cmd/video-server` 通过（17.8MB）。

### 关键 Bug 修复（MediaMTX v1.20.1 版本差异）
- 控制 API 是 **`/v3/`** 前缀，不是 `/v2/`：`GET /v3/paths/list` 返回 `{itemCount,pageCount,items[]}`（数组字段是 `items` 非 `paths`）；单路径用 `online`(bool)/`source`(可空) 字段，没有 `state`。已更新 manager.go(Health/PathsList/Path 结构)、stream.go(映射 items/online)、monitor.go(online→online 否则 offline)。
- WebRTC 读(播放)走 **WHIP/WHEP**：端点 `POST http://127.0.0.1:8889/<path>/whep`，Content-Type `application/sdp`，返回 **201** + SDP answer。原代码 POST `/<path>` 会 404。已更新 manager.go WebRTCOffer（URL 改 `/whep`，接受 200/201）。
