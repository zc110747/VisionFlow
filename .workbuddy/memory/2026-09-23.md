### 教训（已升级到全局 playbook §11 / §7.4）

1. **夹具必须无损。** JPEG 下 stb_image 与 libjpeg-turbo 解码同一图：
   584177/614400 像素一致、最大差 3 LSB、16919 像素差 >1 → 残差被抬到 0.43 px
   （真实移植误差只有 0.0017 px）。噪声比信号大 250 倍，**恰好掩盖要抓的亚像素 bug**。
   换 PNG 后两侧逐字节一致，残差立刻掉到亚毫像素。
2. **基准脚本自己会错。** 官方 `_preprocess` 的 `pad_bias[0]=left / [1]=top`
   藏在 `if` 分支里，誊抄时漏掉 → 基准里每个框偏移 +160 px、选到了另一只手
   （0.70 vs 0.99），看起来像"网络选错了手"。**差分对不上先怀疑基准**，
   并用中间产物（掌心框 / anchor index）逐级定位分叉点。
3. **锚点表的参考副本必须独立誊抄**，不能用被测公式生成，否则是循环论证。
4. **`cmd.exe` 中转被沙箱拒**（Bash 与 PowerShell 两侧都拒），且
   `cmd.exe //c "x.bat"` 在 Git Bash 下会**静默空跑并返回 exit 0**。
   跑 .bat 只有 `./x.bat --no-pause < /dev/null` 一条路；
   要精确控 target / grep 零警告就用手工 MSVC env，
   **注意 Debug 首次配置需要 SDK 的 `rc.exe`/`mt.exe`**（否则报 "compiler broken"，与代码无关）。

### `kCurledRatio` 0.90 → 1.10（本轮唯一行为改动）

**为什么旧值必错**：0.90 是 P1c 时没有握拳样本的占位值。实测两段独立稳态：

| 手指 | 稳态开掌（55 帧/10.8s） | 稳态握拳（14 帧） |
|---|---|---|
| index | 1.587 – 1.782 | **1.222 – 1.398** |
| middle | 1.621 – 1.875 | **0.850 – 0.983** ← 冲到 0.983 |
| ring | 1.516 – 1.734 | 0.731 – 0.871 |
| pinky | 1.429 – 1.534 | 0.722 – 0.963 |

⇒ 旧阈值下真握拳只剩 1 指 extended / ≤2 指 curled，拿不到 0.75 票，
**14 帧真握拳里 11 帧输出 `UNKNOWN`**（`gesture_candidate` 明明已是 FIST）。

新值：最差手指簇间距 **`[0.983, 1.429]`**，1.10 比握拳簇高 0.117、比开掌簇低 0.329，
且**必须** < `kExtendedRatio`(1.15)——`hand_classify_gesture()` 是 `if/else if`，
**死区就是 `[kCurledRatio, kExtendedRatio]`，两者交叉会让死区静默失效而不是报错**。

**几何限制（Phase 1 不修）**：**index 指握拳时永不投 curled**（MCP5 离腕最近，比值仍 1.2–1.4）。
⇒ FIST 只靠 middle/ring/pinky 三指，**恰好卡在 `kGestureVote=0.75` 等号上**，
三指缺一即丢手势。根治要按手指归一化或用 PIP/DIP，属分类器改动。

### ⚠️ 自我更正：我上一条提交里有一处**过度外推**

提交 `e9e8b8c` 的注释/提交信息写的是「**index 指在握拳时永不投 curled**」，
依据是**单次**握拳样本（index 1.222–1.398）。**新数据推翻了它**：

| 手指 | 松拳（14 帧） | 紧拳（10 帧） |
|---|---|---|
| **index** | **1.222 – 1.398**（>1.15 ⇒ 投 extended） | **0.614 – 1.971**（中位 0.829 ⇒ 多数投 curled） |
| middle | 0.850 – 0.983 | 0.464 – 3.720（中位 0.679） |
| ring | 0.731 – 0.871 | 0.339 – 3.048（中位 0.551） |
| pinky | 0.722 – 0.963 | 0.376 – 2.154（中位 0.444） |

**正确结论**：index 是四指里最不可靠的、**也是唯一跨越两个阈值的指头**——
"怎么握就怎么投"。**middle/ring/pinky 在两次握拳里都 ≤ 0.983**，是可靠的三指，
FIST 实际只靠这三指且卡在 `kGestureVote=0.75` 等号上。
**教训**：单次样本只能说"这次如此"，不能写成"永远如此"。
`kCurledRatio = 1.10` 本身**不受影响**（紧拳最低压到 0.339，距 1.10 仍有 ≥0.117 余量）。
