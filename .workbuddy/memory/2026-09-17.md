## 3. 修掉的两个真实缺陷（都由测试暴露）

1. **`)` 提前闭合 if 块**：汇总里 `if (…) echo … (range 5-12) ) else (…)` 让**两个分支都打印**、
   且 `)` 被吞。改为**单行 if**（块外 `(`/`)` 是字面量），已验证输出正确。
2. **LF-only 换行导致 `call :label` 间歇性失败**：出现
   `系统找不到指定的批处理标签 - pok`，且**前后同名调用有的成功**；
   真正危害是变量保留上一次的值（`PCODE=200`）⇒ 产出**假 FAIL**
   （"POST aimode rejects ai-bogus 得到 200" 就是这么来的，不是服务端问题）。
   **改成 CRLF 后 13/13 PASS。**
