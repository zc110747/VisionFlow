## 主窗体新增「进度条 + 音量」控制（仅本地视频文件）

- 文件：`src/VisionFlow.Desktop/UI/MainForm.cs`、`src/VisionFlow.Desktop/Playback/PlayerController.cs`
- 需求：进度条 + 音量控制，仅 `SourceKind.LocalFile` 可用；摄像头/网络相机一律禁用（置灰）。
- 进度条：TrackBar(0~1000) + 当前/总时长标签，`System.Windows.Forms.Timer`(200ms) 轮询 `_player.PositionSeconds`/`Decoder.DurationSeconds` 刷新；拖动时 `_seeking` 挂起定时刷新，松手 `CommitSeek()`→`_player.Seek()`。
- 音量：TrackBar(0~100) 接 `PlayerController.Volume` 占位属性（当前无音频后端，不发声，仅暂存 + 日志）。
- 修复 seek 后进度跳回：PlayerController 以「已呈现帧计数 + seek 基准秒数」推算 PositionSeconds，Seek() 时挪基准；否则下一帧按旧帧计数回写会让拖动失效。
- 验证：Debug/Release 双构 **0 警告 0 错误**（TreatWarningsAsErrors 基线）。WinForms GUI 交互需本机真机验证（沙箱无显示）。
- 约束：启用范围按用户确认「仅本地视频文件」；音量按「UI 占位+存值」落地，待音频链路补全再接。
