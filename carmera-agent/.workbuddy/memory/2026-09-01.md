## start-camera-agent.bat 无法工作：根因定位与修复（已验证通过）

### 现象
用户执行 `start-camera-agent.bat` 后流程不工作。tests/finished/agent.log 显示 agent 启动后立刻退出；
mediamtx.log 显示 ffplay 随后连上来但报 `no stream is available on path 'camera01'`。

### 根因
脚本默认 `CAMERA_ID=1`，但本机只有一个摄像头 **Camera 0**（UVC Control，240×240@8fps）。
→ 管线 `mfvideosrc device-index=1` → `gst_base_src_start: Failed to start`
→ `Failed to set pipeline to PLAYING` → `Failed to start stream. Exiting.`
→ agent 进程直接退出（不是重连，是启动阶段失败），mediamtx 上根本没有发布者 → ffplay 404/EOF。

### 修复（start-camera-agent.bat）
1. 默认 `CAMERA_ID` 由 `1` 改为 `0`（第一台摄像头，通用默认）。
2. 新增 **(2.5) 摄像头索引自动校验/回退**：启动 agent 前先跑一次
   `"%EXE%" --list > tests\finished\cameras.txt 2>nul`，用
   `findstr /b /c:"Camera "` + `tokens=2` 提取可用索引（`/b` 行首匹配可避开
   `[info] Camera Agent starting` 这类日志行，stderr 已 2>nul 抑制，解析后删除临时文件）；
   若配置的 CAMERA_ID 不在列表中且列表非空 → 自动回退到第一个可用索引并打印
   `[AUTO] camera index N is not available - using index M`；
   枚举失败（无摄像头 / GStreamer 不在 PATH）则保留原索引并打 `[note]`，交给后续诊断提示。
   - 注意：回退提示里用 `_old_id` 保存旧值再 echo，避免 if 块内 `%CAMERA_ID%` 取到块前旧值造成显示歧义。
   - echo 内容仍不能含 `()`（cmd 块内未转义 `)` 会提前闭合块，历史坑）。

### 验证（原生 PowerShell 实跑，非 Git Bash）
- 输出全绿：`[OK] camera-agent.exe / mediamtx / ffplay` → `[OK] mediamtx ready` →
  args `--camera 0 --stream camera01 --server 127.0.0.1 --port 8554 --auto` →
  `[OK] camera-agent STREAMING` → `[OK] mediamtx publishing` → `[3/3] Starting ffplay viewer`.
- agent.log：`device-index=0`、`Negotiated capture format: 240x240 @ 8fps`、
  frames 稳定增长（1→47，约 7fps，0 dropped，~713kbps）。
- mediamtx.log：`is publishing to path 'camera01'`、`is reading from path 'camera01', with TCP, 1 track (H264)`。

### 调试方法上的两个坑（重要，下次直接照做）
1. **Git Bash 里跑 .bat 不可信**：`./start-camera-agent.bat --no-pause` 无任何输出且 exit 1，
   是 MSYS 环境干扰，**不是脚本真的失败**。
2. **`cmd //c "bat > file"` 会进 cmd 交互模式**（打印 Windows 版本横幅后停在提示符），不能用。
3. **正确做法**：用**原生 PowerShell** 运行并重定向到文件，再读文件：
   `& .\start-camera-agent.bat --no-pause 2>&1 | Out-File -FilePath ...\launch_out.txt -Encoding utf8`
   （PowerShell 的 stdout 在本环境不回显，必须落文件再读）。

### 环境确认
用 PowerShell `Get-Command` 验证：系统 PATH 已含
mediamtx(`D:\data\agent-tools\mediamtx_v1.20.1_windows_amd64`)、
ffplay/ffmpeg(`...\ffmpeg-master-latest-win64-gpl-shared\bin`)、
GStreamer(`C:\Program Files\gstreamer\1.0\msvc_x86_64\bin`)。
→ 脚本按裸名调用工具的写法没问题，不必再硬编码路径。
